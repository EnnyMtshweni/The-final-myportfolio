CASE STUDY

Market Stock App (FinTrack)

A real-time stock lookup tool built with React — search any symbol and get live price data back in seconds.

  • React
  • JavaScript
  • HTML & CSS
  • Vite
  • Alpha Vantage API
View Live Demo View Repo

// the_problem

Most free stock-tracking sites bury the one thing people actually want — a current price — under ads, charts, and unrelated news. I wanted something that did one job well: type a ticker, get a clean, accurate answer immediately.

I also wanted the exercise for myself — I hadn't built anything before that depended entirely on a third-party API with rate limits, occasional bad responses, and real network latency to design around.

// the_approach

I built the app in React with Vite for a fast local dev loop, and wrote a custom data-fetching hook that wraps the Alpha Vantage API — handling the request, the loading state, and error state in one place so every component that needs stock data can just ask for it.

  • Search: a debounced input so the app isn't firing a request on every keystroke.
  • Data hook: a single custom hook centralises fetch, loading, and error handling so the UI stays simple.
  • Resilience: Alpha Vantage's free tier rate-limits aggressively, so the hook surfaces a clear "try again" state instead of failing silently.
  • Styling: plain CSS, kept deliberately minimal so the numbers stay the focus.

// the_impact

The app does exactly what it set out to do: search any symbol, get a live price back, no clutter. More importantly, it's where I actually learned how to design around a rate-limited third-party API — treating "the request failed" as a normal state to design for, not an edge case to ignore.
